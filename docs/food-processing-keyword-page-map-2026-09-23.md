## 防止页面意图混淆

- 总系列页负责全范围发现，分类页负责功能和型号比较，场景页负责具体组合及排除项。产品总览不复制所有分类页长文。
- “bakery preparation”仅是前处理设备组合。已有“bakery-pastry kitchen package”承接整店厨房方案，二者互链并明确烤炉等边界。
- 同型号的铝芯/铜芯、带护罩/不带护罩、机械/变频版本不是可随意合并的同一报价。本次仅选择明确配置，记录在清单和询价中。
- 型号长尾先在分类页正文、规格展开区和图片 alt 中自然出现。总页上的筛选与 `#machine-*` 锚点不是新的可索引页面，不宣称它们是独立SEO落地页。
- 页面不重复堆“厂家”“工厂直销”“最低价”等无依据词；采购服务、产品供货、交付运输分别说明责任。
- 本次公开目录不上传原始供应商PDF，避免把收款账户、联系人等无关内容带入公开资产。
