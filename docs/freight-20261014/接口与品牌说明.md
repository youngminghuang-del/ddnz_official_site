# 首轮实现范围与接收接口

日期：2026-10-14。本地候选；未发布，非整个货运修复包验收。

## 接收链路与统计

- 货运使用 `src/components/GetAQuote.tsx` → `@formspree/react useForm("mdabvqbd")` → `@formspree/core` → `POST https://formspree.io/f/mdabvqbd`。SDK从现有HTML表单生成FormData，接收端为外部Formspree，不存在本仓库自建货运提交API。
- 既有字段 `Inquiry_Type / Selected_Service / Origin / Destination / Estimated_Weight_KG / Estimated_Volume_CBM / Lead_Goal / Product_Category / Product_Subcategory / Lead_Source / Source_Article_Slug / UTM_* / name / email / phone / industry / message` 保留。已填写数值仍按字符串 `35.5 KG`、`2.5 CBM` 提交，保留小数，不把清空转为0。
- 未知字段以 `Unknown — awaiting cargo details` 进入原字段；新增 `Weight_Status / Volume_Status` 为 `unknown` 或 `customer_estimate`。未知和估计分别记录，不能将这些客户估计当作仓库实测。无默认350kg/2.5m³；它们仅为输入框灰色示例，未成为value。
- 原有自动批量货量预设（45kg/0.3m³、480kg/3.2m³、12500kg/68m³）移除，避免用猜测替代客户资料；用户可填任一已知量，留空另一项，并可明确清空为未知。
- 0、负数、非有限数及非数字阻止进入联系步骤；原有姓名及Email/电话至少一项校验保留。补通用接口错误显示，失败后仍可重试。未增加没有后端的上传控件。
- 保留 `quote_form_start / quote_form_submit_attempt / quote_form_submit / rfq_submit_success / quote_form_error / quote_form_abandon`。成功事件仍由SDK `state.succeeded`触发，`successTrackedRef`和生命周期去重保留。没有将按钮点击计为成功，没有额外发送客户资料至分析。
- `analyticsPolicy.ts`已有localhost及`ddnz_test=1`抑制；`analyticsPayload.ts`过滤姓名/Email/电话/备注等敏感参数；运行时测试验证收集策略与脱敏。本轮没有新造统计系统，也未声称已核验生产分析入库。
- 产品采购由 `get-a-quote.tsx`根据Lead_Goal分流至`TradeSupportInquiry`。产品选型、数量、目的地和overviewBrief沿既有quoteLinkPolicy交接，本轮不改该契约。
- 浏览器使用独立无头Chrome上下文，禁止所有非本地请求；Formspree请求只由Playwright route返回模拟成功/失败。没有销售测试线索或真实外发。浏览器和单元测试可以证明客户端契约，不能证明未取得访问权的Formspree后台规则、通知收件、CRM自动化或生产入库。若后台另有强制数值字段规则，集成前须在沙箱检查未知字符串处理；不得用0兜底。

## 本轮必要品牌与交互规范

- 沿用DDNZ字标、紫色交互/焦点、浅底和现有按钮体系，不重画国家页视觉或修改公司能力陈述。
- 手机顶栏地球图标+当前语言；面板显示8语本语言全名（中文/English/Русский/Français/Español/العربية/Português/Türkçe），44px以上触控目标。展开货运及滚动菜单不会改变语言按钮位置。
- 移动语言面板和长导航分开开关，切换保留既有路由、查询参数与锚点；沿用产品/文章语言路由规则，不制造不存在的译文。葡语/土语国家页在SPA切换时可能先读到旧全局语言，因此改为按当前URL取该页语言；不更改任何国家正文。Escape关闭并返焦，点外部/移出焦点关闭；RTL使用逻辑定位。桌面保留原语言入口并改为完整名称。
- 嵌入表单统一浅底、深字，去掉会把浅底控件文字强制变白的深色全局覆盖；手机减少外层和表单多层内边距。数值字段单列、单位独立、状态说明可换行；联系字段有可见标签，按钮可换行。
- 手机货运表单进入视口时让WhatsApp/返回顶部悬浮控件避让，离开后恢复；页脚联系入口不变。
- 样式范围限定共用导航、GetAQuote及四地区模板共用的`.dark-form-container`，不改国家服务正文、运价、时效或目的国法规。
