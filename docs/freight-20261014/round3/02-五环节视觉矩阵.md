## 共用制作决策

1. 每国主线只放一组五步骤，每步一个明确画面+一句价值，避免再增加长清关说明。
2. 至少让第3与第5环节有可识别的当地节点；第1、2环节用本次需求差异。国旗/天际线不能单独承担全部国家特色。
3. 只使用素材组已验收素材。现有M049/M046标签保留China；暂无获核的Qatar/Oman实际交付照片。
4. 公共成品只需一条“询盘规划示例”说明；来源、假设与版权审核留在本交接表，不把表格整段放前台。
