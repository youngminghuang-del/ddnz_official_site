## 集成选择

- 01：目的地地图节点、图旁EN/AR短句与事实来源。地图使用素材组最终manifest，不在工程临时猜坐标。
- 02：每国五环节视觉矩阵，供选图/裁切/布局。不是前台大表。
- 03：每国一组五步旅程及CTA，直接用于EN/AR。若页面已有同义模块，合并替换重复文字，避免再堆五个长段落。
- 优先结构：短目录 → 需求/中国端操作 → 五步旅程（图文） → 当地港口/城市地图及进口交付说明 → 常见问题/询盘。地图可以嵌入旅程第3–5步旁，避免重复。
- 手机端每步短标题+短段；视觉位置保持阅读顺序。阿语 `dir=rtl`，英文地名/1688及数字按需隔离；地图北向不翻转。
- 现有中国端视频各用一次：Qatar收货、Oman装柜。图注保留China，不能改成Hamad/Sohar handling。

## 内容验收点

1. Hamad港≠Doha Port；Doha城市标签不是港口图标。
2. SOHAR港≠Muscat；不能把Oman全境写成仅Sohar入口。
3. 货类是此次需求示例；没有typical/popular/top imports或虚构贸易比例。
4. 六张台球桌≠六箱；无猜测重量、尺寸、台面材质、海运天数或报价数字。
5. 无实线直航、船舶实时标点、ETA、完成勾选；城市环境照不称DDNZ交付实拍。
6. EN/AR同步保留示例身份、港口选择条件及进口/卸货的核对动作。
