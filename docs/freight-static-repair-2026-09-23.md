# 运输国家页静态正文修复及需求承接

状态：本地下一版本已完成，未发布生产站。修复原报告列出的 99 个页面版本（19 个国家路线，6 种语言）；未新增网址，sitemap 仍为 332 页。

## 实现

构建在现有静态页面生成后，复用四套实际运输页组件、国家数据与翻译，将此前空白的 React 根容器补成完整页面。LanguageProvider 接受仅供明确初始化使用的语言参数；普通浏览器初始化逻辑保留。现代化运输页面已有静态内容，继续沿用各自渲染器。

构建时使用本地 esbuild 打包服务器渲染入口，不启动网络服务。不复制一份独立的国家运输文案。标题、国家选择、路线资料、FAQ 与新增规划区均来自客户端组件。静态输出消除动画初始 opacity:0，避免在 JavaScript 执行前隐藏正文，并补充运输样式。生成全部候选结果并验证后才写回文件。

## 关键词及需求承接

- 核心层：沿用现有国家运输 H1、标题及路线正文，例如中国至哈萨克斯坦货运。
- 运输方式层：中亚和俄罗斯页补充铁路／公路完整路线比较；海运目的市场页补充 FCL／LCL 服务范围比较。内容涵盖提货、集货、装载、目的地操作与最终交付；不承诺未经确认的班次或时效。
- 产品与场景层：加入食品加工机械从中国运至当前国家的规划说明，具体包括型号、数量、包装尺寸、毛重、吊装、防护、电机和配件资料；受限部件按实际货物审核。
- 城市及交付层：例如哈萨克斯坦页列 Almaty / Astana，秘鲁页列 Lima / Callao，要求明确收货地址、卸货条件及进口方，并区分到港、到站和送货到址。城市是询价示例，不是服务覆盖承诺。
- 关联路径：设备采购页 → 国家运输页的货物规划；运输页 → 食品机械、商用厨房、集货出口服务及带目的地的货运询价。

以上为意图层级，不代表已验证的搜索量。没有创建“每型号 × 每国家”的薄弱页面，也没有把亚洲目的地误写为亚洲多国供货。

## 验证

- 原 99 个空正文版本全部生成成功，99 个 H1 均唯一。

- 检查 138 个国家／区域运输地址没有空根容器；对修复的 99 页逐个检查 H1、规划区、采购和服务内链、货运询价意图和目的地参数、静态可见性。
- 所有修复页的本地页面链接均有对应构建文件。
- 同一构建重复预渲染后，99 页的 SHA-256 完全不变。
- TypeScript 检查、完整预览构建、SEO／部署检查通过；相关运输和语言路由测试 19/19 通过。
- 浏览器抽查英文哈萨克斯坦、阿语秘鲁的国家与新增规划区。

## 后续构建防回归

`build` 和 `build:preview` 已加入国家页预渲染和检查。亦可在构建后单独运行：

```sh
npm run audit:country-pages
npm run audit:search-intent
```

若国家页返回空根容器、修复页缺少 H1／规划区、货运询价参数错误、内链文件不存在或静态正文仍隐藏，构建检查会报错。
