# 运价参考更新流程

只制作候选包，不直接更新生产。可以按两周或每月人工发起；页面继续使用季度参考和“实际价格询价”，不承诺固定更新日期。旧生产快照、完整原始记录与每批审阅结果均保留。

1. 在已登录平台人工选择起运港与目的港。确认选中标签已经形成，等结果加载完成，再核对返回行的真实起运港；输入了名称但没有选中不算筛选成功。区分 CARTAGENA,CO 与同名西班牙港。保存每条运价、三个柜型、币种、时效、航线、中转、有效期原文、完整杂费、备注和限重。无记录单独标记，不填零价；来源没列杂费也不当作免费。
2. 原始成本和备注只放部署目录外。规范化文件标记 `kind: internal-freight-cost-snapshot`、`currency: USD`、`period: 2026-Q4`、采集日期、明确的 reviewedCountries 与 `reviewStatus: reviewed`。每条有人工维护的稳定 sourceKey。没有平台公开稳定ID时，不按新的排序重新编号；同承运方案出现多条相似记录须人工辨认，不能只用最低价或最快时效自动合并。
3. 用只读基线的SHA核对并运行 `scripts/freight-rate-batch.mjs`。生成候选公开JSON、增删改与异常报告、内部ID映射。脚本不覆盖输入基线，也不执行部署；报告和映射禁止写入 public/dist。只替换 reviewedCountries 范围，其他国家原公开记录保持原样。缺少某国数据会停止；真正无记录须显式列入 emptyCountries，撤回动作仍需审阅差异报告。
4. 对新成本只在导出时计算一次对客参考：10%毛利率对应成本÷0.9，向上取到分；不是乘1.1。未知金额保留null。USD主运费与RMB/USD杂费分别计价，不混币种、不把按票费用按柜重复乘算。旧公开报价不重新加利润，已有sourceKey沿用同一个公开路线ID。禁止把对客快照作为内部成本再次输入。新增费用名称须核对并补充八语标签，不能为过校验而丢弃收费项。
5. 人工审阅 added/removed/changed，尤其价格、航程、中转、费用和适用条件；核对长中转、缺失费用、未知港口或空查询。每条价格与自身时效一起保留，不能拼接两个方案。备注内的条件费用不得原样进入对客页面；保留内部原文，客户页说明需按具体货物确认。季度值不是锁价或可订舱报价。
6. 按候选公开记录重算FCL概览已知时效区间。LCL、空运与含税清关到门仍单独询价，其公开规划参考与FCL记录分开说明。检查国家页、区域筛选、三柜型、费用展开、八语询价预填、RTL与手机布局、schema可见内容一致及成本隔离后出预览。只有另获发布指示才走main/CMS整合与发布。
7. 发布后核公开接口哈希/数量、页面和私有路径404，保留可回滚的上一版公开快照。跨季度时先更新endpoint、period校验、ID命名与相关八语季度文案并复测；当前运行时到2027年会停止展示2026-Q4参考，不把旧数据自动改标签沿用。

CLI参数：`--source`内部规范化文件、`--baseline`当前公开快照、`--candidate`新候选、`--report`外部差异报告、`--ids-output`外部映射、`--expected-sha`基线SHA；后续批次用`--ids`加载上次映射。所有文件路径由操作者明确提供，无凭据、无自动采集账号或公开内部资料。

4288审阅候选新增34条，原366条保持原值；是否已发布以该批正式发布验收记录为准。实际数量与异常以该批验收记录为准。没有新增外部定时任务，也不自动发布。

更新实操补充：相同国家重新采集无内容变化时，保留已有路线和目的港覆盖的原顺序，使候选字节和SHA保持不变。改价更新仍沿用稳定ID，新增记录追加、明确撤回的记录才删除。不能用输入排序变化制造无意义版本。

本地CLI使用项目JSON加载器：`node --import tsx scripts/freight-rate-batch.mjs ...`。427条的本批非洲候选未发布；哥伦比亚12条复采与400条基线的零变化演练已验证，不重复加利润。
