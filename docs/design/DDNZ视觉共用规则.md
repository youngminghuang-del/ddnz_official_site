# DDNZ 产品页面视觉共用规则

本轮为已上线页面的风格收拢，不替换批准Logo、产品图片、内容或采购流程。基线main3e212d2（含并行PR96备件文章成果）。中央实现 src/styles/ddnz-visual-system.css；已有品牌色及共用CatalogueHeroMedia为依据，不另造一套视觉身份。

## 同一角色共用的基础

- 文字海军蓝#10243f，辅助文字#52647c，紫色#763c9c用于导航/选中/焦点；主要采购动作珊瑚色#b94625，悬停#9f391e。颜色承接现有品牌，不让每个品类自行选主按钮颜色。
- 内容宽1280px，含边距的外框1360px；页边距clamp(18px,3vw,40px)。首页、产品页从同一正文边线开始，首页的大图可更有表现力。
- 产品首屏H1桌面最高60px/750字重、手机36px；首页保留66px品牌层级，工具/文章标题保留自身角色。中文采购动词和品名按自然短语换行，原文字不变；阿拉伯语使用原有Arabic字体与较松行距，保持RTL。
- 主要按钮48px最小高度/8px圆角；媒体框16px圆角、轻边线；不加浮夸阴影。段落/区块间距按角色分组，不把全部模块做成相同卡片。
- 被后加载的专属样式覆盖的位置，直接引用共享变量；不靠追加!important或重复特异性竞争维持一致。

## 有意保留的差异

- 首页：团队形象和品牌表达。
- 餐厨：实际应用场景大图与设备目录，保留细分类导航和渐进展开。
- 咖啡：单台产品大图，无须复制其他类别的三图轨道；木纹及咖啡场景保留。
- 音响、电源：产品配置组合，保留自身产品配色；灯光/包装图案不改色。
- 手机膜：包装/工艺和价格比较；比较工具、brief及原选品路径不套首屏模板。
- 食品、电动车、储能：复用同一首屏基础参数，保留真实机型和各自选型内容。
- 场景图使用cover，单品图使用contain；不能为统一外观裁掉产品、改机型或把示意图当实拍。

## 后续页面接入

优先使用 CatalogueHeroMedia 与共享变量。只展示一台产品时省略items，组件不会输出空缩略图区；有多个真实型号或品类入口时提供items。中文采购标题可用CatalogueHeroHeading保持短语完整，其他语言保留正常单词换行。

新增规则限定在产品根类及语义组件内，不把所有按钮/所有H1全站强制覆盖。运输执行、文章阅读、表单步骤及详情工具保持自己的布局。

六代表页×八语×两屏宽=96组合，食品/电动车/储能六入口×中英阿三语×两屏宽=36组合，共132组合，另加六代表页320/1920宽度12组合，合计144；无横向溢出或重复H1。405测试与类型通过；音响标题测试改为验证H1文字内容而非特定HTML串，确保增加换行标记没有改变原文字。

现有impeccable上下文引擎因缓存写入/安装条件未运行；按已读取polish/craft-floor和项目现有页面直接进行修整及浏览器检查，未声称运行自动设计评分或独立双评审。没有生成或修改产品照片，没有新性能/价格/MOQ承诺。

承接F105只读检查与用户明确实施授权，已把规则从六类首屏扩展到页内模块和英文专属模板。先合入最新main86858a4，保留PR97文章；本批不发布。

- 页面底`--ddnz-brand-paper` #fffdfb；独立产品/内容面`--ddnz-surface-raised` #fff；采购说明、表单等分组`--ddnz-surface-soft` #f4f5f6；选中底`--ddnz-surface-selected` #f0e9f6。品牌飘带、真实场景和有含义的工具图仍可保留；不要为每个普通模块另造浅紫或灰底。
- 普通分隔/卡片边`--ddnz-brand-line` #dce3ea；输入框边`--ddnz-control-line` #8493a5；焦点及选中仍用紫色，错误/成功/禁用保留自身含义。没有把选中边与普通分隔线合并成同一灰线。
- 控件8px、普通卡片12px、媒体/图集16px；过滤胶囊、圆形关闭钮和图示标记按用途保留。不要把小控件套成大圆角卡片。
- 珊瑚色表示主要采购动作；紫色保留导航、比较和已选状态。`ddnz-action`用于明确的采购入口，不能无条件加给所有按钮。同一选择按钮在选中时可呈紫色。
- `ddnz-page`、`ddnz-surface-soft`、`ddnz-line`、`ddnz-radius-card`、`ddnz-control`为utility模板的语义接入口；不改变DOM顺序、文案或表单行为。既有CSS在声明源头接共用变量，避免按需加载后重现旧规则。少量跨模板中性utility映射在共享样式内集中维护。
- 产品H1通常60px/手机36px，正文段落1.8行高，H2共用响应式层级；首页、阅读、工具、货运及紧凑组合有意保留角色尺度。保留现有栅格、阅读宽度与RTL字体，不将全部段落强制塞进同一窄列。
- 手机配件采购框取消负向外扩，按正文边线对齐；采购支持内部普通顶线减为1px。320px共用Logo缩小显示尺寸，原始裁切和比例不改，保留菜单及语言按钮。

没有修改产品/场景图片像素，也没有修订事实文案、schema或询价数据；图库、对比、数量与询价交接继续使用原实现。图片原生灰底、场景深色和少量工具功能色属于内容特征，不以CSS强行抹掉。F105指出的中文翻译质量另行跟进，未擅改文案。
